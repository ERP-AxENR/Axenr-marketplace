# Onduleurs Huawei SUN2000 / LUNA / SmartLogger

Base de connaissance construite à partir des manuels constructeurs, normes et forums d'installateurs (sources listées en fin de chaque référence). Charge la référence utile :
- `huawei-alarmes` : Alarmes Huawei SUN2000 : ID, causes, diagnostic
- `huawei-procedures` : Procédures terrain Huawei (isolement, I-V, firmware, code réseau, RMA, garanties)
- `huawei-cas-terrain` : Cas terrain Huawei tirés des forums

`use_skill({skill: "pv-onduleurs-huawei", reference: "<nom>"})`. Applique la méthode de la skill `pv-diagnostic-methode`.
